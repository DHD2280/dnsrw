# DNSRW
Rewrite system DNS by Wi-Fi or mobile network - LSPosed

# Supported Versions
Android 15+, LSPosed API 102

# Tested Models
nubia Z80 Ultra (Android 16, NebulaAIOS2.0.26MR_NX741J)

# Instructions
1. Install the APK and enable the module in LSPosed.
2. Ensure the module scope only includes "System Framework (`system`)" and restart the device for the module to take effect.
3. Set the default `DNS` for Wi-Fi and mobile networks in the app. You can also set rewrite rules for individual networks.
